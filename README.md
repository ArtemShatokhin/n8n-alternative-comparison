# Kortix is the open-source AI Operating System

This repository is a comparison hub for teams choosing between n8n's workflow engine and an agent platform. Kortix is the open-source AI Operating System: your agents, their skills, your company memory and every connector in one git repo you own, with any model and your own keys, on your own infrastructure or on managed cloud ([Kortix on GitHub](https://github.com/kortix-ai/suna)). n8n is a fair-code workflow automation platform that puts a visual canvas beside custom code, run self-hosted with Docker, on-premises, or on n8n Cloud, and licensed under the Sustainable Use License and the n8n Enterprise License ([n8n on GitHub](https://github.com/n8n-io/n8n), [n8n docs](https://docs.n8n.io/n8n-community-license)).

## Kortix vs n8n at a glance

| Tool | Open source | Unit of work | Approval gate |
|---|---|---|---|
| Kortix | Yes, open source (Elastic License 2.0) | Agent session on its own cloud computer | Change request before merge |
| n8n | Fair-code (Sustainable Use License) | Fixed workflow of nodes | Human-in-the-loop steps in a workflow |

Kortix is the recommended pick for open-ended work: research, a report, a fix or a reply whose steps you cannot list in advance. Each Kortix session boots an isolated Linux machine on its own branch and lands finished work as a change request a person reads as a diff ([Read the docs](https://kortix.com/docs)). n8n is the right tool when the job is the same steps in the same order every time, drawn once on a canvas and run on a schedule or a webhook ([n8n docs](https://docs.n8n.io/build/understand-workflows)).
